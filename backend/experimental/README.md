# Experimental Reference Bank

The category-specific normal-reference memory was evaluated during earlier
detector iterations and is intentionally excluded from the Phase 1 identity.

Phase 1 is a pure zero-shot CLIP detector: it uses only the frozen CLIP
encoder, compositional prompt ensembles, multi-layer local scoring, calibrated
temperature scaling, and the existing uncertainty/localization machinery.

This file is retained only as a decision trace. It is not imported by the
Phase 1 runtime, calibration script, or evaluation script.

The historical reference-cache artifacts were removed from the active
repository because they are no longer part of the detector.
